LINUX SOFTWARE LAB / DIRECTORY

Find the right tool.

Katalog software desktop yang dibangun dengan fokus pada kegunaan, keterbukaan, dan informasi rilis yang transparan. Cari berdasarkan masalah yang ingin diselesaikan, bukan hanya nama aplikasi.

CATALOG POLICYOne source of truth.

Metadata terpusat. Pencarian di browser. Tidak ada pelacak pencarian atau API eksternal.

Prinsip proyek ↗
01 / ALL SOFTWARE

Browse the collection.

Semua software diurutkan dan difilter dari katalog yang sama. Setiap kartu menjelaskan kategori, platform, fitur, serta status pengembangannya.

Tekan / atau Ctrl K untuk fokus ke pencarian. Pencarian lokal mencakup nama, deskripsi, fitur, kata kunci, tag, kategori, dan platform.

Memuat katalog…Metadata divalidasi otomatis sebelum deployment
02 / TRANSPARENCY

Clear status. No fake downloads.

Link unduhan baru muncul jika aset rilis benar-benar tersedia. Konsep visual diberi keterangan dan tidak disajikan sebagai tangkapan layar aplikasi rilis.

Katalog ini adalah situs statis. Nama, fitur, kategori, tag, platform, dan status berasal dari data/software.json. Untuk menambah software, kontributor mengikuti aturan metadata dan menjalankan validator lokal sebelum pull request.
