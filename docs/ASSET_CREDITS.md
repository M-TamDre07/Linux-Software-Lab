# Asset credits and usage

## First-party artwork

The following assets are original Linux Software Lab project artwork maintained in this repository:

- `public/assets/images/linux-software-lab.svg` — site mark and favicon.
- `public/assets/images/linux-software-lab-social.svg` — editorial social-preview illustration.
- `public/assets/images/paketscope-icon.svg` — PaketScope product icon.
- `public/assets/images/paketscope-preview.svg` — conceptual PaketScope interface artwork.
- `public/assets/images/sorot-icon.svg` — Sorot product icon.
- `public/assets/images/sorot-preview.svg` — conceptual teleprompter artwork.

These original SVGs are project artwork, not screenshots from a released binary and not third-party icon packs. The product preview illustrations must continue to be labelled as concepts until replaced by genuine captures from tested builds.

## Third-party assets

No third-party icon or illustration pack is currently required by the custom SVGs listed above. If external assets are introduced later, record the original source URL, asset name, license, attribution requirement, retrieval date, and any trademark restrictions here before committing them.

## Review checklist

- Keep icons visually coherent with the established site design.
- Prefer local, optimized assets; do not add a remote asset CDN for decorative graphics.
- Do not copy logos or distinctive artwork from other projects or Linux distributions without checking the applicable license and trademark rules.
- Check keyboard focus, contrast, responsive cropping, and meaningful alternative text when an asset is used in the interface.
- Social crawlers vary in SVG support. Before promoting social sharing, verify the preview on the intended platforms and add a raster PNG fallback if needed.
