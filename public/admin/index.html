PRIVATE / MAINTAINER CONTROL ROOM

Data ekosistem. Terjaga.

Panel privat untuk memeriksa seluruh mirror katalog, termasuk baris yang belum dipublikasikan, memantau sinkronisasi, dan membuka sumber data resmi.

Autentikasi Supabase + izin database RLS. Halaman ini sendiri bukan batas keamanan.
01 / SIGN IN

Masuk sebagai maintainer

Gunakan akun yang sudah dibuat di Supabase Authentication. Pendaftaran publik tidak tersedia dari halaman ini.

Login yang berhasil belum otomatis menjadi admin. ID akun harus tercatat aktif di daftar izin database.

ACCESS CONTROL

Akun belum diberi izin admin.

Akun berhasil diautentikasi, tetapi tidak ditemukan sebagai maintainer aktif. Tidak ada data katalog yang ditampilkan.

UUID akun kamu

Pemilik proyek harus menambahkan UUID ini secara manual ke tabel public.lsl_admin_users melalui SQL Editor Supabase. Jangan membuat policy yang menjadikan semua pengguna admin.

02 / CATALOG OVERVIEW

Status ekosistem

Data di bawah dibaca dari mirror Supabase yang dikunci oleh RLS. Konten tetap bersumber dari katalog GitHub.

Maintainer aktif

Edit sumber resmi ↗ Workflow sinkronisasi ↗ Table Editor ↗
GitHub tetap menjadi sumber utama.

Perubahan katalog dilakukan pada public/data/software.json melalui proses review, lalu GitHub Actions menyinkronkannya ke Supabase. Panel ini sengaja tidak menulis langsung ke mirror agar perubahan tidak tertimpa sinkronisasi berikutnya.
