DIREKTORI SOFTWARE / LISO LAB

Temukan alat yang tepat.

Katalog software Linux dengan fokus pada kegunaan, transparansi, dan status rilis. Cari berdasarkan masalah yang ingin diselesaikan, bukan hanya nama aplikasi.

CATALOG POLICYSatu sumber data.

Metadata disinkronkan dari repositori resmi. Pencarian tetap lokal; JSON lokal menjadi fallback.

Prinsip proyek ↗
01 / SEMUA SOFTWARE

Jelajahi koleksi.

Temukan software berdasarkan nama, kategori, platform, atau statusnya. Setiap kartu menjelaskan fungsi dan tahap pengembangan dengan terbuka.

Tekan / atau Ctrl K untuk fokus ke pencarian. Pencarian lokal mencakup nama, deskripsi, fitur, kata kunci, tag, kategori, dan platform.

02 / TRANSPARANSI

Status jelas. Tidak ada unduhan palsu.

Link unduhan baru muncul jika aset rilis benar-benar tersedia. Konsep visual diberi keterangan dan tidak disajikan sebagai tangkapan layar aplikasi rilis.

Katalog ini adalah situs statis. Nama, fitur, kategori, tag, platform, dan status berasal dari data/software.json. Untuk menambah software, kontributor mengikuti aturan metadata dan menjalankan validator lokal sebelum pull request.
