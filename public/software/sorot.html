TENTANG SOROT

Teleprompter desktop yang mengikuti alur bicara.

Sorot membantu pengguna menampilkan naskah saat presentasi, perekaman, atau berbicara di depan kamera. Informasi produk, unduhan, dan riwayat versi dipisahkan agar pengguna dapat menilai sendiri kecocokan paket sebelum memasang.

Versi 1.0.23 telah diterbitkan sebagai rilis stabil setelah pengujian fungsional dan pemeriksaan kelayakan oleh maintainer. Paket .deb dan Python wheel memiliki checksum SHA-256. Kanal stable menandai versi ini sebagai rilis utama yang direkomendasikan; kompatibilitas tetap mengikuti format dan lingkungan yang dinyatakan pada manifest, bukan jaminan untuk seluruh distro Linux.

Cakupan dukungan: laporan QA versi 1.0.23 tersedia dan keputusan rilis stable telah disetujui maintainer. Paket .deb ditujukan untuk keluarga Debian/Ubuntu yang kompatibel; Python wheel memerlukan interpreter serta dependensi yang sesuai. Arch Linux tetap menjadi target rencana dan belum memiliki paket native. Cocokkan SHA-256 dan periksa dependensi sebelum pemasangan.

Versi 0.9.0 tetap tersedia sebagai arsip .deb untuk kebutuhan lama, tetapi statusnya archived dan tidak direkomendasikan untuk instalasi baru. Versi lebih lama juga ditandai sebagai Beta/testing dan akan meminta konfirmasi sebelum unduhan.

INSTALLER TERMINAL RESMI

Periksa dulu, baru pasang.

Installer membaca distro dan arsitektur lokal, mengambil manifest rilis, memilih paket native yang cocok, lalu memeriksa SHA-256 sebelum menjalankan package manager. Jalankan sebagai pengguna biasa; skrip hanya meminta hak administrator pada tahap pemasangan paket.

Status kompatibilitas: Sorot 1.0.23 stable saat ini menyediakan paket native .deb dan Python wheel. Target pengujian paket native adalah Debian 13. Arch, Fedora/RPM, dan openSUSE/SUSE belum memiliki paket 1.0.23 yang tervalidasi; installer tidak akan mengganti paket distro lain sebagai fallback.

1. Unduh skrip resmi dan periksa isinya 
curl --fail --location --show-error --max-time 30 \
  https://raw.githubusercontent.com/M-TamDre07/Linux-Software-Lab/main/apps/sorot/install.sh \
  --output /tmp/sorot-install.sh

sed -n '1,260p' /tmp/sorot-install.sh
2. Deteksi distro, lihat artefak, dan uji tanpa memasang 
bash /tmp/sorot-install.sh --detect
bash /tmp/sorot-install.sh --list
bash /tmp/sorot-install.sh --version 1.0.23 --dry-run
3. Pasang setelah hasil deteksi dan dry-run sesuai 
bash /tmp/sorot-install.sh --version 1.0.23

Jangan menjalankan skrip dengan sudo bash. Tidak perlu menyalin perintah package manager manual. Untuk distro yang belum memiliki artefak cocok, pemasangan akan dihentikan secara aman. SHA-256 memeriksa konsistensi file, tetapi bukan tanda tangan penerbit.
