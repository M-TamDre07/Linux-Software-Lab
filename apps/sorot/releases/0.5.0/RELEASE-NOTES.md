# Sorot 0.5.0 Beta

**Status katalog:** testing  
**Jenis paket Debian:** sorot_0.5.0_all.deb (Architecture: all)  
**Paket ini bukan rilis stabil.**

Versi ini menyediakan aplikasi teleprompter desktop Linux dengan editor naskah, overlay, kontrol pemutaran, markup jeda/catatan, ekstensi deklaratif dan berbasis kode, serta integrasi AI/cloud yang opsional.

Berkas yang disimpan bersama catatan versi ini adalah paket Debian, source archive tar.gz, source archive ZIP, manifest rilis, checksum SHA-256, laporan pengujian, dan catatan kesiapan rilis.

## Batas pengujian

Laporan proyek mencatat 378 tes lulus pada Ubuntu 24.04 dengan Python 3.12 dan PySide6 6.12.0 serta hasil build berulang yang identik. Ini bukan bukti instalasi bersih Debian 13 atau uji compositor desktop nyata. Overlay pada KDE Wayland/XWayland, sesi X11/Wayland nyata, integrasi layanan eksternal, dan aksesibilitas tetap harus dinilai berdasarkan pengujian terpisah.

## Integritas artefak

Periksa SHA256SUMS sebelum menggunakan paket atau arsip sumber. Jangan menganggap file pada versi baru sebagai pengganti file di direktori versi ini. Perbaikan sumber yang diterapkan oleh CI setelah artefak ini dibuat belum menjadi bagian dari paket 0.5.0 yang diarsipkan.
